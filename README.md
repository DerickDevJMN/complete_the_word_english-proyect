 **Live Website:** [https://completetheword-game.vercel.app/](https://completetheword-game.vercel.app/)

---

##  Game Modes

### 1.  Multiple Choice Quiz
- **Objective:** Answer vocabulary questions by picking one of three choices (A, B, or C).
- **Features:** 12 curated questions, immediate explanations, single-attempt score validation, and a dynamic progress bar.

### 2.  Complete the Word *(Star Feature)*
- **Objective:** Fill in missing letters to discover the hidden English word based on a clue.
- **Features:** Chunky interactive letter tiles, 15 progressive challenges, automatic whitespace trimming, case-insensitive comparison, and browser-powered audio pronunciation.

### 3.  Guess the Word
- **Objective:** Read beginner-friendly riddles and deduce the target vocabulary word.
- **Features:** 12 riddle challenges, 3 attempts per riddle, visual attempt counters, unlockable hints, and immediate feedback.

---

##  Key Features

- **100% Vanilla Tech Stack:** Built with pure HTML5, CSS3, and JavaScript — zero frameworks, zero external dependencies.
- **Sound & Speech Engine:** Built-in Web Audio API tone synthesizer (chords, buzzers, victory fanfare) and Web Speech API word pronunciation.
- **Modern & Accessible UI/UX:** High-contrast color palette (Royal Blue & Electric Purple), ARIA accessibility labels, keyboard support (`Enter` to submit, `Esc` to return home).
- **Responsive Design:** Seamless layout across mobile smartphones, tablets, and desktop computers.
- **Encouraging Feedback:** Positive reinforcement system awarding +10 points per challenge with performance summaries.

## How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/complete-the-word.git
   ```
2. Open the project folder.
3. Double-click `index.html` to launch the website in any web browser (Chrome, Edge, Firefox, Safari). No web server or build step required!
